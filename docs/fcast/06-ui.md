# 06 - The cast UI

All cast UI is standard Material 3, D-pad navigable (`focusBorder` on every clickable), uses theme
tokens, and localizes every string in `app/src/main/res/values/metrolist_strings.xml` (`cast_*`, `casting`,
`enable_casting*`, `stop_casting`, plus the shared `connected` / `share` / `copy_link` / `link_copied` /
`retry`).
`scripts/ui-audit.sh` enforces no new hardcoded strings / hex / font sizes / raw `AlertDialog`s.

## Entry points

| Surface | File | Look |
| --- | --- | --- |
| Full-player artwork | `ui/player/Thumbnail.kt` → `CastButton` | dark disc overlaid top-right of the artwork |
| Mini player | `ui/player/MiniPlayer.kt` | bordered circular chip |
| Settings | `ui/screens/settings/PlayerSettings.kt` | "Enable casting" `SwitchPreference`; turning it on opens `CastDownloadDialog` |

## Shared launch + state (`ui/player/CastButton.kt`)

- `rememberCastButtonState()` collects `connectedDeviceFlow` + `CastEnabledKey` once and returns null
  (hidden) unless casting is enabled or a device is connected.
- `CastIcon(connected, idleTint, size)` is the one `cast` / `cast_connected` glyph.
- `openCastPicker(playerConnection, menuState)` is the one launch path: `startDiscovery()` then shows
  `CastPicker` in the shared menu bottom sheet (`LocalMenuState`).

The artwork disc and the mini-player chip keep distinct wrappers but both render
`rememberCastButtonState()?.let { … CastIcon(…) }`, so change the gate or launch behaviour here once.
The artwork disc is the one raw colour (`Color.Black.copy(alpha = 0.45f)` with a white icon): the
legible-over-any-artwork exception (a radial scrim vanished on dark art).

## The picker (`CastPicker`, `ui/player/CastBottomSheet.kt`)

Self-contained: collects `connectedDeviceFlow`, `discoveredDevicesFlow`, `castLibState` and
`castDeviceRefresher.refreshing`. States:

- **Lib not ready** (`Idle` / `Downloading` / `Failed`) - consent + Download, progress, or the error (+ Retry for `DOWNLOAD_FAILED`)
  (mirrors `CastDownloadDialog`).
- **Connected** - a "Stop casting" row.
- **Searching** - spinner, "same Wi-Fi" hint, and the FCast install section (link + share/copy buttons).
- **Devices found** - one `CastDeviceRow` each; the tapped row shows a spinner + "Connecting…" and
  further taps are ignored until the attempt resolves.

While ready and not connected, the header has a refresh button (spinner while refreshing). Whenever
the lib is `Ready` (on open, or right after a download) the picker runs `startDiscovery()` + one
automatic `castDeviceRefresher.refresh()` ([03](03-discovery-and-connection.md)).

Connect runs `service.castConnector.connect(...)` on **`service.scope`**, not the Activity-bound
`playerConnection.scope`: backgrounding the app mid-connect would cancel the latter, skipping the
connector's timeout abort (a pending attempt could then surprise-connect) and stranding the row spinner.
`connectingDevice` is reset in a `finally`. The picker only maps the result: `Connected` dismisses the
sheet, `NoStream` / `Failed` toast (`cast_stream_failed` / `cast_connect_failed`). The sheet is not
dismissed on tap, so a failure is visible.

## The consent dialog (`CastDownloadDialog`)

Built on the shared `DefaultDialog`; same states and strings as the picker; auto-dismisses at `Ready`.
Both surfaces show a determinate bar + "Downloading cast support… N%" from
`CastLibState.Downloading.progress`, indeterminate while it is null ([02](02-on-demand-native-lib.md)).
A one-shot `cast_download_success` toast fires on the `Downloading → Ready` edge, only on the surface
that started the download.

## Conventions and local pieces

- Share/copy use the shared `context.shareText` / `context.copyToClipboard` (`shareFcast` / `copyFcast`).
- `CastCircleButton` (round share/copy/refresh buttons) and `CastDeviceRow` are local composables built
  on shared primitives; no shared component matches their shape.
- Drawables: `cast.xml`, `cast_connected.xml`, `content_copy.xml`. Open alignment item: the copy-link
  button uses `content_copy`, while the rest of the app uses `R.drawable.link` for copy-link.
