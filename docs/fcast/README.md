# FCast casting

Zemer can stream the current track to an [FCast](https://fcast.org) receiver (an open casting protocol;
the SDK also speaks Chromecast). The phone resolves the same googlevideo stream it would play locally,
hands the receiver a **LAN relay URL** that proxies it through the phone (`MusicService.relayedStreamUrl`
→ `CastStreamRelay`, direct googlevideo URL as fallback), then acts as a remote control and a mirror of the
receiver's clock. Local audio stays paused while casting.

These pages are hand-authored rationale (not generated by `docs/generate.py`); update the relevant page
when you change the cast code.

## Why FCast (not the Cast SDK)

Google's Cast SDK needs Play Services and a registered Cast app id. FCast is open and LAN-only with no
cloud registration. The trade-off is a native `.so`, kept out of the APK and fetched on demand
([02](02-on-demand-native-lib.md)).

## Mental model

One `FCastDiscoveryHandler` (a `MusicService` field) owns the SDK: discovery, connect, load, transport,
and the receiver's state as `StateFlow`s. Three thin seams route transport to it **only while connected**:
`CastAwarePlayer` (media session / notification / Android Auto / headset), `PlayerConnection` (in-app
UI) and `MusicService.onStartCommand` (the widget). The control plane - end-of-track auto-advance (the SDK
does not advance a queue), the single track-change reload, error recovery, the idle watchdog and
disconnect recovery - is `CastController`, owned by the process-scoped `MusicService` so a session keeps
advancing after the Activity is destroyed.

## Key facts

- **SDK:** `org.futo.gitlab.videostreaming.fcast-sdk-jitpack:sender-sdk-minimal:0.4.0` (package
  `org.fcast.sender_sdk`) + `net.java.dev.jna:jna:5.13.0@aar`.
- **Native lib:** `libfcast_sender_sdk.so` is excluded from the APK and downloaded from the
  `ZemerTeam/zemer-cast` release `sdk-0.4.0`, SHA-256 pinned per ABI (`arm64-v8a`, `armeabi-v7a`).
- **Enable flag:** `CastEnabledKey` (`"castEnabled"`, default off).
- **"Casting" everywhere means `FCastDiscoveryHandler.isConnected`** (`remoteConnectionState` is
  `Connected`), never `connectedDevice != null` (set before the device is ready).
